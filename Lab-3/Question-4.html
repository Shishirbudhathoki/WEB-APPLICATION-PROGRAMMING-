Design and develop a simple interactive webpage that displays a light bulb image along with a control button.When the user clicks the button, the light bulb should toggle between ON and OFF states by changing its image dynamically. At the same time, a status message on the page should update to clearly indicate whether the bulb is currently ON or OFF. Additionally, the button text should change accordingly (for example, “Turn ON” when the bulb is OFF and “Turn OFF” when the bulb is ON). Implement the functionality using JavaScript to handle the click event and manipulate the DOM elements dynamically.
